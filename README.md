# Hand Gesture Recognition Using CNN

## 📌 Project Overview

This project implements a Convolutional Neural Network (CNN)
to recognize and classify different hand gestures from images.

The model is trained on the LeapGestRecog dataset and can
classify 10 different hand gesture categories.

## 🎯 Objective

To develop a hand gesture recognition model that can
identify and classify hand gestures from image data.

## 📂 Dataset

Dataset: LeapGestRecog

Source: Kaggle

Total Images: 20,000

Number of Classes: 10

Images per Class: 2,000

Image Size: 64 × 64 pixels

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Pillow
- Scikit-learn
- Google Colab

## 🧠 Model Architecture

The CNN model consists of:

- Convolutional layers
- Max Pooling layers
- Flatten layer
- Fully Connected Dense layers
- Dropout layer
- Softmax output layer

## ⚙️ Project Workflow

1. Dataset acquisition
2. Image preprocessing
3. Image resizing and normalization
4. Training and testing data split
5. CNN model development
6. Model training
7. Model evaluation
8. Gesture prediction
